# Wiz ties Microsoft Agent Framework package compromise to release pipeline certificate

[Source](https://siliconangle.com/2026/11/19/wiz-ties-microsoft-agent-framework-package-compromise-to-release-pipeline-certificate/)

(U) United States — SiliconANGLE reported that two malicious versions of Microsoft's official Python package for its Agent Framework appeared on PyPI through Microsoft's own publisher account and were removed within about an hour. Citing Wiz researchers, the article said the attacker appeared to hold a client certificate and private key for Microsoft's Engineering System Release Pipeline; an initial publishing attempt from Amazon Web Services address space was blocked before a second attempt from Microsoft-owned space succeeded. A .pth file collected environment secrets and credentials for Azure, npm, Git, Docker and Hugging Face, while Wiz's limited webhook data indicated three unique successful thefts; Microsoft had not responded to requests for comment.
