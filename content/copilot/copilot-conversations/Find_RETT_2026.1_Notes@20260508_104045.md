**ai**: ### How to Run `grep -r "![[RETT 2026.1]]" .` on Your Obsidian Vault Folder

This command searches **all raw Markdown files** recursively for the exact literal string `![[RETT 2026.1]]`, bypassing Obsidian's indexing or plugin parsing (e.g., embeds via `<embedded_note>` or Dataview). It's ideal for verifying raw source content.

#### Step-by-Step Instructions (Cross-Platform)

1. **Locate Your Vault Folder**:
   - In Obsidian: `Settings > Files & Links > Show vault root folder in file explorer` (or right-click vault name in sidebar > "Reveal in Finder/Explorer").
   - Navigate to the vault root (e.g., `Threat_Estimate_2027`).

2. **Open Terminal/Command Prompt in the Vault Folder**:
   | OS | Steps |
   |----|-------|
   | **Windows** | Shift + Right-click in vault folder > "Open PowerShell window here" (or "Open command window here"). |
   | **macOS** | Right-click vault folder > Services > "New Terminal at Folder" (or `cd /path/to/vault` in Terminal.app). |
   | **Linux** | Right-click > "Open in Terminal" (or `cd /path/to/vault`). |

3. **Run the Grep Command**:
   ```
   grep -r "![[RETT 2026.1]]" .
   ```
   - **Flags explained**:
     | Flag | Purpose |
     |------|---------|
     | `-r` | Recursive (searches all subfolders/files). |
     | `.`  | Current directory (vault root). |
   - **Expected Output**:
     ```
     path/to/note.md:Line with ![[RETT 2026.1]]
     ```
     - If none: No matches (empty output).
     - Files are `.md` only by default; add `--include="*.md"` for safety: `grep -r --include="*.md" "![[RETT 2026.1]]" .`

4. **Advanced Variations** (if basic misses due to whitespace/escapes):
   - Case-insensitive: `grep -ri "![[RETT 2026.1]]" .`
   - Regex for block refs: `grep -r "!\[\[RETT 2026\.1[#^]" .` (matches `![[RETT 2026.1#^id]]`).
   - Line numbers + context: `grep -rnH --color=always "![[RETT 2026.1]]" .` (`-n`: line #, `-H`: filename, `--color`: highlights).
   - Exclude folders: `grep -r --exclude-dir=".obsidian" "![[RETT 2026.1]]" .`

5. **Alternatives if Grep Unavailable**:
   - **Windows (no Git Bash/PowerShell)**: Use PowerShell: `Select-String -Path "*.md" -Pattern "!\[\[RETT 2026\.1\]\]" -Recurse`
   - **Obsidian Plugins**:
     - Install "Dataview" > Run query in console: `LIST FROM "" WHERE contains(file.content, "![[RETT 2026.1]]")`
     - "Advanced URI" or "Quick Switcher" for regex search.
   - **VS Code**: Open vault folder > Ctrl+Shift+F > Search: `![[RETT 2026.1]]` (files to include: `*.md`).
   - **Ripgrep** (faster): Install `rg` > `rg "![[RETT 2026.1]]"`.

- Grep scans **raw bytes**, catching literals exactly.
