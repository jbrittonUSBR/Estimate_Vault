# LiteLLM supply chain attack started with an exposed master key

[Source](https://www.theregister.com/security/2026/10/26/litellm-supply-chain-attack-started-with-an-exposed-master-key/5305544)

(U) LONDON, U.K. — LiteLLM traced a supply-chain attack that published a poisoned PyPI package to a master key accidentally committed to a public GitHub repository in May and never revoked, which an attacker used to gain owner-level access.
