# North Korea-linked Hackers Hide a Backdoor Inside HAProxy

[Source](https://securityaffairs.com/198656/apt/north-korea-linked-hackers-hide-a-backdoor-inside-haproxy.html)

(U) SEOUL, South Korea — Security Affairs reported on September 8, 2026 that North Korea-linked hackers hid a backdoor inside the source code of HAProxy, the load-balancing software, at the edge of two South Korean companies' networks. According to research by Rapid7, a previously undocumented Linux toolkit targeted organizations in South Korea's automotive and media industries with minimal detection, using a HAProxy instance named "ted backdoor" alongside trojanized versions of crond, agetty, atd, sshd, and polkitd. The framework enabled attackers to execute remote commands, inject malicious scripts into web traffic, harvest credentials, and conduct long-term surveillance while keeping the load balancer operating normally.
