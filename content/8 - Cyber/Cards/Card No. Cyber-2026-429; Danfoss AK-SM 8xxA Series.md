# Danfoss AK-SM 8xxA Series

[Source](https://www.cisa.gov/news-events/ics-advisories/icsa-26-328-03)

(U) WASHINGTON — CISA issued an advisory on November 24 for a critical stack-based buffer overflow, CVE-2026-129713, in Danfoss AK-SM 8xxA controllers version 5.4.0 and earlier that could allow unauthenticated remote code execution with webserver privileges. The flaw in an unauthenticated CGI handler can be triggered by crafted HTTP/S POST requests, causing memory corruption and webserver restart; the affected equipment is deployed worldwide in commercial facilities and Danfoss is headquartered in Denmark. Danfoss planned to address it in a future 5.5.x release and recommended keeping devices off the internet, using VPNs and Strict Mode; CISA said no public exploitation had been reported.
