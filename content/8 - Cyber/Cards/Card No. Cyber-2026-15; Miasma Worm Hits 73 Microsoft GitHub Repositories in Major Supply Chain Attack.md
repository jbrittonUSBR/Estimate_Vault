(U) A software supply chain attack impacting over 50 npm packages via abuse of the binding.gyp file has been reported. The behavior in this attack aligns with the Mini Shai-Hulud family of self-replicating secret theft malware. Multiple AI-related npm packages, including Vapi AI Server SDK, unofficial SDK for Ollama, AutoTel MCP, and Executable Stories MCP, have been impacted. The Miasma supply chain attack campaign has expanded into AI npm packages VAPI AI server and AI SDK Ollama. The attack has also impacted 10 additional npm packages, including a credit card-related package and n8n community node for ContaAzul API. The Hades variant of Miasma Worm has been linked to the Mini Shai-Hulud, compromising 37 PyPI packages via Python startup hooks to silently steal developer credentials. Endor Labs researchers have quarantined all six malicious packages using Shai-Hulud worm published on PyPI registry.
