# Security boffin claims airport group left API keys in client-side JavaScript for four years

[Source](https://www.theregister.com/cyber-crime/2026/09/09/security-boffin-claims-airport-group-left-api-keys-in-client-side-javascript-for-four-years/5295192)

(U) MANCHESTER, United Kingdom — Security researcher Scott Helme said his analysis supports a claim by the cyber extortion group FulcrumSec that Manchester Airports Group (MAG) exposed overprivileged Iterable API keys in client-side JavaScript, potentially exposing data belonging to roughly 8.8 million customers. Using the Internet Archive's Wayback Machine, Helme found the keys first appeared on the websites of Manchester, Stansted, and East Midlands airports in June and July 2022 and remained exposed until August 2026, giving anyone viewing the page source the ability to access customer profiles, bookings, and purchases, and to delete records. MAG, which described the incident as "a hack, not a lapse," declined to comment on Helme's conclusions and said it disputed his "no hacking required" characterization while continuing to investigate with the Information Commissioner's Office and the National Crime Agency.
