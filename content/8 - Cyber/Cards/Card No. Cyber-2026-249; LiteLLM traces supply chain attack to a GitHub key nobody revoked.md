# LiteLLM traces supply chain attack to a GitHub key nobody revoked

[Source](https://cryptobriefing.com/litellm-supply-chain-attack-exposed-github-key/)

(U) United States — LiteLLM traced a supply-chain compromise to an exposed GitHub master key that it said had remained active for about five months, Crypto Briefing reported. The project’s postmortem said an attacker used the key to poison an official release, which had an estimated 49,000 downloads; those findings were attributed to LiteLLM.
