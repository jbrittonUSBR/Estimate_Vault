# One HTTP Request, Every File on the Server: GitLab’s CVSS 10 Commits-API Flaw Hits Active Exploitation Within Hours

[Source](https://forkast.news/one-http-request-every-file-on-the-server-gitlabs-cvss-10-commits-api-flaw-hits-active-exploitation-within-hours/)

(U) SINGAPORE, Singapore — A path traversal flaw in GitLab's commits API, tracked as CVE-2026-85706 and rated CVSS 10.0, allowed a single unauthenticated HTTP POST request to read arbitrary files from any GitLab server hosting at least one public project, according to Forkast. GitLab released patches on September 10, 2026, for affected Community and Enterprise Edition versions, but an estimated 20,000-plus self-managed instances remained at risk. The watchTowr honeypot network observed in-the-wild exploitation attempts at 06:00 UTC on September 11, and the Cybersecurity and Infrastructure Security Agency added the flaw to its Known Exploited Vulnerabilities catalog the same day, setting a September 14 remediation deadline.
