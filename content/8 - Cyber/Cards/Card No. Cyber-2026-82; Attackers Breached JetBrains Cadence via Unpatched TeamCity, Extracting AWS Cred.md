# Attackers Breached JetBrains Cadence via Unpatched TeamCity, Extracting AWS Credentials

[Source](https://thehackernews.com/2026/09/attackers-breached-jetbrains-cadence.html)

(U) UNITED STATES — Threat actors exploited an unpatched vulnerability in JetBrains TeamCity to breach the company's Cadence service and extract Amazon Web Services credentials, according to a report by The Hacker News. The intrusion was said to have occurred between August 8 and August 24, 2026, and to have been discovered on August 23. The attackers reportedly accessed a 2024 server backup containing credentials as well as multiple AWS IAM users and secrets, after which the server at api.cadence.jetbrains.com was taken offline. The flaw, tracked as CVE-2026-63077 with a CVSS score of 9.8, was added to the Cybersecurity and Infrastructure Security Agency's Known Exploited Vulnerabilities catalog on August 5, 2026, and JetBrains urged customers to rotate credentials.
