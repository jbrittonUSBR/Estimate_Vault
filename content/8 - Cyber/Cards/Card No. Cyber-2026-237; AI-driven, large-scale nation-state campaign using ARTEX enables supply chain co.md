# AI-driven, large-scale nation-state campaign using ARTEX enables supply chain compromise

[Source](https://www.microsoft.com/en-us/security/blog/2026/10/21/storm-0940-uses-artex-agentic-ai-connectwise-supply-chain-compromise/)

(U) Online — Microsoft Security Research and Threat Intelligence described a campaign using the ARTEX agentic-AI tool to compromise ConnectWise and target downstream organizations. Microsoft attributed the activity to a nation-state actor it tracks as Storm-0940 and reported that AI agents automated parts of the operation; these are vendor threat-intelligence assessments.
